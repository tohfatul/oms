\# OrderFlow Overview



OrderFlow is a cloud-native order processing platform designed as a personal portfolio project.



The application includes a React and TypeScript frontend, a .NET API, PostgreSQL, event-driven processing, AWS infrastructure, and an AI assistant.



Users authenticate through Microsoft Entra ID.



Authenticated users can browse catalog products, create orders, and retrieve their own orders.



The AI assistant can search catalog products, retrieve order information, prepare orders, and create orders after explicit user confirmation.



OrderFlow does not currently support inventory quantity tracking, submitted-order modification, cancellation, refunds, payment processing, or shipment tracking.
